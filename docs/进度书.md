## 当前所处阶段

当前处于总体阶段五“语义排序与智能核验”的**评测验证子阶段**，对应 [评测与测试规划](ScholarFlow_评测与测试规划.md) 第 29–33 节：

```text
已完成：候选快照 → A/B/C/D/E 离线结果与评分 → 零命中覆盖诊断
当前：受控 Query Agent 查询策略试验的候选覆盖验证
```

这里的关键门槛是：排序只能重排已封存的候选，不能补回未被来源召回的金标论文。因此在确认候选覆盖前，不应根据 A/B/C/D/E 的代理分选择模型配置。

### 已确认的覆盖事实

基础 20 条共享候选集合上的首轮配置出现零检索命中，故已进入候选覆盖诊断与查询策略实验，而非继续扩大排序矩阵。

为避免读取 Gold 标题、作者或 arXiv ID，Query Agent v4 只接收原始查询及已显式 QueryIntent 条件，并对下列三条查询各调用一次：

| 查询标识 | Query Agent 状态 | 快照状态 | 局部覆盖诊断 |
| --- | --- | --- | --- |
| `pasa:auto-dev:AutoScholarQuery_dev_950` | 已生成 | 50 篇候选 | 1 篇金标、0 命中；金标/候选强标识符为 1/50 |
| `pasa:auto-dev:AutoScholarQuery_dev_420` | 已生成 | 50 篇候选 | 4 篇金标、0 命中；金标/候选强标识符为 4/50 |
| `pasa:auto-dev:AutoScholarQuery_dev_907` | 已生成 | 快照与诊断目录已生成 | 待复核 `diagnostic.json`；不得先假定其有或无覆盖 |

Query Agent v4 的实际用量为 3 次调用、958 输入 Token、861 输出 Token、估算费用 ¥0.00192736。每条后续候选快照调用均已在执行前单独生成预估；这不改变来源的 RPS、重试、超时或 429 冷却保护。

950 和 420 的诊断均显示金标与候选都有强标识符，却无 `papers_match-v1` 命中。因此可确认的是“当前快照没有覆盖金标”；不能单独归因于 OpenAlex、Query Agent、规范化、身份规则或排序。

## 当前禁止事项

- 不对 950、420 运行 BGE-M3、Cross Encoder 或 DeepSeek：当前候选未覆盖金标，排序无法产生有效检索比较。
- 不把 v4 的单条新快照复制进原 20 条共享集合，伪造同一 QueryIntent 来源；局部诊断必须记录 `selected_query_ids`。
- 不因修改 `evaluation_top_k`、报告或代理分而重调学术 API。
- 不自动下载数据、调用学术 API、Query Agent、DeepSeek 或加载本地模型；真实执行始终由用户明确发起，并在调用前审阅资源预估。
- 不将本地效率、结构或综合代理分称为公开赛题官方得分。

## 下一步规划

1. **复核 907 局部诊断。** 如目录仍有 ACL 限制，用户先重置该目录权限；随后只读取 `diagnostic.json` 与 `diagnostic.md`，确认 907 的金标数、候选数、强标识符可比性和命中数。
2. **结束 v4 小样本候选覆盖试验。** 若 907 仍为 0 命中，则冻结结论为“本轮三个 Query Agent 改写均未在 50 篇第一轮候选中确认覆盖”，停止这一批在线候选调用；不进入排序或 DeepSeek 阶段。若 907 有命中，也只记录为单条局部事实，不能外推为 20 条开发集结论。
3. **仅做规划，选择下一种候选覆盖干预。** 在不读取 Gold 论文内容的前提下，比较下列候选并由用户确认一项：调整来源路由/引入不同学术来源、调整经明确预注册的 `source_recall_count`、或改进不泄漏 Gold 的 QueryIntent 策略。该规划必须分别冻结查询、来源、候选数量、快照标识和资源上限；不得通过已知金标反向调参。
4. **补齐策略实验所需的评测契约后再执行。** 若要将少量新快照与评分对接，先新增可审计的“按明确 query_id 封存 Gold 子集/策略实验 manifest”边界，不能手工拼接旧 20 条集合。该能力未实现前，不运行局部 A/B/C/D/E 评分。
5. **只有新策略快照确认覆盖后，才进入排序比较。** 对同一份新快照按 A（RRF）、B（BGE-M3）、C（Cross Encoder）、D（BGE-M3 + Cross Encoder）进行离线比较；先关闭 DeepSeek，只让表现最好的少量配置进入独立 E 对比，并在调用前重新生成预估。
